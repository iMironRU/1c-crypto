# Инструкции для Claude Code

Мини-курс «Криптография в 1С»: 8 уроков по 45 минут, все написаны
(`status: ready`). Сопровождается демонстрационной конфигурацией и рабочими
примерами кода.

Перед любым действием прочитай контекст:

- **`spec/constitution.md`** — принципы курса и фундаментальное правило
  «всё — двоичные данные». Если предложение выходит за рамки конституции —
  откажись от него.
- **`spec/specification.md`** — для кого курс, что читатель знает на входе,
  метрики успеха, ограничения.
- **`spec/decisions.md`** — лог решений.
- **`docs/style-guide.md`** — канон серии плюс надстройка курса: формат урока,
  правила для кода, блок «В боевой системе».
- **`docs/binary-data.md`** — развёрнуто о двоичных данных.
- **`docs/certificates.md`, `docs/providers.md`, `docs/glossary.md`** — справочные материалы.

## Структура репозитория

```
chapters/
  NN_slug/
    NN-01_urok.md                 ← текст урока  (# Урок N. Название)
    NN-02_kontrolnye-voprosy.md   ← 5 контрольных вопросов
    NN-03_otvety.md               ← ответы

code/           ← исходники примеров: hashing, encryption, signature, jwt, https, utils
configuration/  ← демонстрационная конфигурация 1С
docs/           ← справочные материалы и канон стиля
spec/           ← конституция, спецификация, решения
reviews/        ← отчёты панели ревью (не идут в сборку)
```

Frontmatter обязателен:

```yaml
---
status: ready     # draft | review | ready
---
```

## Главное правило курса

> Криптография работает только с байтами.

```
Строка → ДвоичныеДанные → [операция] → ДвоичныеДанные → Base64 / HEX / хранилище
```

В каждом примере оба преобразования показаны **явно**. Прятать их внутри
вспомогательной функции без объяснения нельзя — именно на этом шаге читатель
ошибается чаще всего.

## Команды

### `/book-write урок-N [тема]`
Порядок: конституция → спецификация → соседние уроки → стиль. `status: draft`.

### `/book-analyze урок-N`
Конституция → спецификация → стиль → консистентность → **проверка кода**:
пример запускается? двоичные преобразования видны? есть `Попытка/Исключение`?

### `/book-plan урок-N`
Уточнить состав урока; решения — в `spec/decisions.md`.

## Что не делать

- Не давать пример, который нельзя запустить.
- Не прятать работу с `ДвоичныеДанные`.
- Не подавать MD5 или голый хеш пароля как рабочий вариант — только как разбор ошибки.
- Не разворачивать параллельный курс по ГОСТ: для этого есть блок «В боевой системе».
- Не менять `status: ready` без явного запроса автора.
- Не изменять `metadata.yaml` напрямую — только через `./book.sh`.
